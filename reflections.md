# SBA 1 Reflection

### Creating and Managing Branches
I made two branches named feature/header and feature/footer. This let me work on the header and footer separately without touching the main branch right away.

### Handling the Merge Conflict
I changed the footer in both branches so they would clash. When I merged feature/header into main, Git showed a merge conflict. I opened index.html, chose the code I wanted to keep from both, saved the file, and made a commit to finish the merge.

### Pull Requests and Code Quality
Pull requests let other people look at my code before adding it to main. Reviewing each other's code helps us find bugs and learn from each other.
